# Upstream Issue Research Plans

Per-issue **research plans** produced under Phase 4 Step 4.1 of
[`../upstream-followup-plan.md`](../upstream-followup-plan.md).

Each plan identifies and organizes the sources of information that will
be reviewed when producing the corresponding report in
[`../upstream-issue-reports/`](../upstream-issue-reports/). The plan
does **not** attempt to write the report or the issue.

## Layout

```
docs/research/
  upstream-issues/
    plan-NN-<slug>.md        <- research plan (THIS folder)
  upstream-issue-reports/
    report-NN-<slug>.md      <- synthesis report
```

`NN` and `<slug>` match across the plan and report for the same item.

## Mandatory pre-work

Before authoring or working from any plan, re-read the curated
authoritative-references list at:

<https://github.com/OS4CSAPI/ogc-client-CSAPI_2/blob/phase-8/docs/research/references.md>

Self-sourcing spec/standard references is forbidden. Gaps must be
surfaced to the user before drafting.
