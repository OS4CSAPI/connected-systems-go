# Issue #25 — Live Tests (HEAD `5f079c3`, base `https://129-80-248-53.sslip.io/csapi-go-head`)

## T1 — server-synthesized inline `@link` carries only `href`

```pwsh
Invoke-RestMethod -Uri '.../datastreams?limit=1'
```

Response excerpt (verbatim):

```json
"system@link": {
  "href": "systems/666ed3fe-bccf-4670-bb85-a0a3c4562772"
},
...
"links": [
  { "href": "https://129-80-248-53.sslip.io/csapi-go-head/systems/666ed3fe-...",
    "rel": "ogc-rel:systems" },
  { "href": ".../datastreams/cf4cd80c-.../observations",
    "rel": "ogc-rel:observations" }
]
```

**Findings**:
- Inline `system@link` has **only** `href`. No `rel`, `type`, `title`, `uid`.
- Supplementary `links[]` entries have `href` + `rel` only. No `type`, `title`,
  `uid`.
- Body's symptom example reproduces verbatim.

## T2 — round-trip preserves user-supplied optional fields

POST `/systems/666ed3fe-.../datastreams`:

```json
{
  "name": "DS-25-rich-link-test",
  ...
  "system@link": {
    "href": "https://example.org/api/systems/abc",
    "rel": "parent",
    "type": "application/geo+json",
    "title": "My System",
    "uid": "urn:test:sys:abc"
  },
  ...
}
```

Response: `201 Created`, `Location:
https://129-80-248-53.sslip.io/csapi-go-head/datastreams/16f5115b-4c90-49df-8db9-e0c06e261e5d`

GET that URL → `system@link` echoed verbatim:

```json
{
  "href": "https://example.org/api/systems/abc",
  "rel": "parent",
  "type": "application/geo+json",
  "title": "My System",
  "uid": "urn:test:sys:abc"
}
```

**Findings**:
- All five optional fields persist through POST → JSONB → GET.
- Acceptance criterion "round-trip POST → GET preserves at least the fields
  the client supplied" is **already satisfied** by current storage. The
  improvement scope is therefore strictly *server-side enrichment of
  server-synthesized links*, not the round-trip path.
