```
HTTP/1.1 201 Created
Location: /datastreams/5a529129-3ad1-4af7-8560-47a5feee8aea
```

GET back: same shape as T1 — no `phenomenonTime` key. The parse-failure path
(silent-discard site A2) is exercised here, not the type-assertion path (A1).
Both classes of failure produce identical silent loss.

## T3 — Control: valid RFC 3339 string array

Request body has `"phenomenonTime": ["2026-01-01T00:00:00Z", "2026-12-31T23:59:59Z"]`.


```json
"phenomenonTime": ["2026-01-01T00:00:00Z", "2026-12-31T23:59:59Z"]
```

Confirms the round-trip works correctly when input is well-formed — so the
defect is uniquely in the silent-discard branches, not in the storage shape.
