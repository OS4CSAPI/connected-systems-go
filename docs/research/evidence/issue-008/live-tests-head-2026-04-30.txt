VERDICT: NEW DEFECT (not documented in issue #8). The spec parameter
         `parent` MUST return resources whose parent matches. Live result
         is empty.

         WHERE parent_deployment_id IN (parentId), and the else branch

         WHERE parent_deployment_id IS NULL. AND'd → impossible.

         Reference: spec parameters/parentIdList.yaml.
